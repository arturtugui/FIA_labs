# Minesweeper Solver Benchmark



Board source: `benchmark_boards.txt` (400 validated answer boards).

All three solvers play the same selected boards using the same deterministic click policy (corner opening, least-risk frontier guess). Timing measures solving only.



Search nodes count tried safe/mine branch values, including failed trials. Values forced by propagation are deductions and are not counted.

Guesses count clicks made when clue reasoning did not prove a safe cell; the fixed opening click is excluded.
