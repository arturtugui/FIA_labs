# Task 2 train/test split

The source has 173 rows and 23 families. A fixed random seed of 42 was used to shuffle within each family. For every family with at least two rows, at least one row is placed in each split and the test count is rounded toward 30%. Singleton-family rows are placed in train so the models can observe those labels; they cannot also appear in test.

Train: 123 rows (71.1%). Test: 50 rows (28.9%). Train contains 23 families; test contains 17 families. The input is the Step 1.11 cleaned file (sorted token sets, lowercase column names, range midpoints, columns more than 80% blank dropped). Blanks are still blank: mode imputation and outlier capping are fitted on the training rows afterwards, in Task 2.2.
