# Task 2.3 multi-way decision tree (least average disorder)

## Method

Disorder of a set: `D = -sum(p_i * log2 p_i)` over the families in the set (0 when homogeneous). For a question, the average disorder is `sum_b (n_b / n) * D(branch b)`. At every node the question with the least average disorder is asked; each branch is then treated the same way using only its own mushrooms, until every branch is homogeneous. A categorical question has one branch per complete cell value at that node (`[x]`, `[f]` and `[f, x]` are three branches). A numeric question is `midpoint <= t?`, with `t` splitting the node's mushrooms as evenly as possible into two groups.

Features (16): `cap-shape`, `cap-surface`, `cap-color`, `does-bruise-or-bleed`, `gill-attachment`, `gill-spacing`, `gill-color`, `stem-surface`, `stem-color`, `has-ring`, `ring-type`, `habitat`, `season`, `cap-diameter-midpoint`, `stem-height-midpoint`, `stem-width-midpoint`. `family` is the target; `name` and `class` are not used.

25 question nodes, 114 leaves, maximum depth 3. Groups of identical training feature rows with different families (impossible to separate): 0.
