## Why not frequency encoding

Frequency encoding replaces a value by how often it occurs. Different values with the same count get the same number, so the model can no longer tell them apart:

| Column | Distinct cell values | Distinct numbers after frequency encoding | Values sharing the number 1/123 |
| --- | --- | --- | --- |
| cap-shape | 23 | 9 | 8 |
| cap-surface | 34 | 8 | 17 |
| cap-color | 44 | 9 | 27 |
| does-bruise-or-bleed | 2 | 2 | 0 |
