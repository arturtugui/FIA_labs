# Pairwise missingness and family adjustment

For each feature pair, overall expected rows assume independent blanks using the overall rates. Within-family expected rows use the product of the two blank rates inside each family, then sum across families. Excess is observed joint blanks minus expected joint blanks, divided by all rows, in percentage points. Positive values indicate more joint blanks than that baseline; negative values indicate fewer. This is descriptive, not a significance test; small families make estimates unstable.
