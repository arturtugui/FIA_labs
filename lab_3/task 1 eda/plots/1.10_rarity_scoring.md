# Rarity score and provisional tiers

## Scoring method

Each observed feature value receives points using its frequency within that feature: a value seen once gets 10 points; otherwise <1% gets 8, <5% gets 5, <30% gets 1, and >=30% gets 0. For multi-valued categorical cells, token points are averaged within the feature so a cell with more listed tokens does not automatically score higher. Numeric midpoint and width values are each grouped into 10 equal-width bins before assigning points; the midpoint/width points are averaged into one contribution per original numeric feature. `name`, `family`, and `class` are excluded. `veil-type` is excluded from this score in line with the proposed >90%-missing column removal, but the source data is unchanged. Missing features are omitted from the raw sum; the sum is normalized to the same 19-feature scale using the number of observed scored features. The score is descriptive, not a biological measure of rarity.

## Tier cut rule

Species are ordered by adjusted score, targeting about 70% Common, 25% Rare, and 5% Legendary. Equal scores are kept together; when a tied score crosses a target boundary, tier sizes can differ slightly from the target proportions.
