# Multi-hot encoding summary

Each observed token becomes its own binary feature, so a cell such as `[x, f]` sets both token columns to 1. Blank categorical cells set all token indicators for that source feature to 0. For features with 15%-80% blanks, an explicit blank indicator is added; sparse features above 80% remain represented by their token-presence indicators. No token was merged or removed at this EDA stage.
