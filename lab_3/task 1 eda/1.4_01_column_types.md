# Column roles and variable types

Categorical letter codes are treated as labels; no meanings or order are assumed without a data dictionary.

| Column | Role | Variable type | Notes |
| --- | --- | --- | --- |
| family | Classification target | Nominal categorical | Predicted by the Task 2–4 classifiers. |
| name | Identifier | Nominal text | Species name; not a model feature. |
| class | Analysis label | Binary categorical | Separate label for analysis and cluster comparison. |
| cap-diameter | Feature | Numeric interval | Range; represented by midpoint for class distribution plots. |
| cap-shape | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
| Cap-surface | Feature | Multi-valued categorical | A cell may list more than one nominal code; some values are blank. |
| cap-color | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
| does-bruise-or-bleed | Feature | Binary categorical | Observed codes are [f] and [t]. |
| gill-attachment | Feature | Multi-valued categorical | A cell may list more than one nominal code; some values are blank. |
| gill-spacing | Feature | Single-valued categorical | One nominal code per nonblank cell; no order assumed. |
| gill-color | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
| stem-height | Feature | Numeric interval | Range; represented by midpoint for class distribution plots. |
| stem-width | Feature | Numeric interval | Range; represented by midpoint for class distribution plots. |
| stem-root | Feature | Single-valued categorical | One nominal code per nonblank cell; many cells are blank. |
| stem-surface | Feature | Multi-valued categorical | A cell may list more than one nominal code; some values are blank. |
| stem-color | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
| veil-type | Feature | Single-valued categorical | One observed code; most cells are blank. |
| veil-color | Feature | Multi-valued categorical | A cell may list more than one nominal code; many cells are blank. |
| has-ring | Feature | Binary categorical | Observed codes are [t] and [f]. |
| ring-type | Feature | Multi-valued categorical | A cell may list more than one nominal code; a few cells are blank. |
| Spore-print-color | Feature | Multi-valued categorical | A cell may list more than one nominal code; many cells are blank. |
| habitat | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
| season | Feature | Multi-valued categorical | A cell may list more than one nominal code. |
